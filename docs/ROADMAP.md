## Критерии готовности MVP
1. Аноним видит только published; черновик не вытягивается anon-ключом (smoke-тест зелёный).
2. Полный цикл модерации работает и защищён RLS, а не только UI-кнопками: UPDATE статуса мимо матрицы отклоняется БД.
3. Публикация в админке → карточка в приложении без ручного обновления (realtime).
4. Избранное/профиль переживают перезапуск приложения и офлайн.
5. Счётчики растут в админке в реальном времени при действиях в приложении.
