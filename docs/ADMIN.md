# Веб-консоль — «Карьера РТУ МИРЭА»

Рабочее место редактора контента: посты, организации и баннеры витрины.
Бэкенд — PocketBase (`https://vmt-mireacareer.l1ratch.ru`), схема и правила — в
`.agent-docs/database-guide.md`.

## 1. Стек и запуск

- Vite + TypeScript, чистый fetch (клиент `src/pb.ts`), без UI-фреймворков и SDK.
- `admin/.env`: `VITE_PB_URL`.
- `pnpm install && pnpm dev` → http://localhost:5173. Сборка: `pnpm build`.
- Вход — учёткой суперпользователя PocketBase (логин/пароль в `.agent-docs/database-guide.md`).
  Пароль в коде не зашит; токен живёт в localStorage.

## 2. Разделы

Всего три раздела — консолью пользуется один администратор (решение по ролям:
см. ARCHITECTURE.md §2; расширение — отдельная задача, когда потребуются).

### Посты
- Вкладки-фильтры по производному статусу: **Актуальные** (published, дата
  наступила, не архив), **Отложенные** (published_at в будущем), **Черновики**,
  **Архив** (end_date в прошлом), **Все**.
- Поиск по заголовку, фильтры по типу (`vacancy|event|internship`) и организации.
- Счётчики 👁/🔖 в таблице, обновление — со страницы просмотра.
- Действия иконками: предпросмотр 👁, правка ✎, опубликовать ✔ / снять ⏏,
  в архив 📦 / вернуть ♻ (меняет end_date), удалить 🗑. Все — с подтверждением.

### Форма поста
Заголовок, тип, формат, организация, описание (HTML, живой предпросмотр),
даты начала/конца, статус, дата публикации (пусто = сейчас; будущее =
отложенная), приоритет/вес, внешняя ссылка, теги, кампусы/институты/направления
(пусто = все, хранится null), обложка файлом (multipart после сохранения JSON).
Счётчики при правке не сбрасываются: PATCH шлёт только изменённые поля.

### Просмотр поста
Карточка «как в приложении» + явное пояснение, что видит студент сейчас
(«виден», «появится 12.10», «в архиве», «черновик»), счётчики, те же действия.

### Организации
CRUD: название, тип (`university_dept|partner|hidden` — hidden скрывает из
списков приложения), описание, сайт, контакты, логотип **ссылкой** (поле url).

### Баннеры
Витрина главной («Актуальное»): заголовок, подзаголовок, ссылка, порядок
(меньше = раньше), активность, картинка файлом. Неактивные анониму не видны.

## 3. Актуальность поста — как считается

Пост в приложении виден, когда одновременно: `status = published`,
`published_at <= now` и (`end_date` пуста или `end_date >= now`).
Просроченный пост уходит в архив сам — вернуть можно, поменяв end_date.
Кнопки «в архив/вернуть» в консоли именно это и делают.
