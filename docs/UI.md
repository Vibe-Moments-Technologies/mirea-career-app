# UI/UX-спецификация — «Карьера РТУ МИРЭА»

Стиль: современный iOS-like (HIG-эстетика поверх Material 3). Приложение адаптивно от 320 dp до планшетов.

## 1. Design tokens (`core/theme/`)

```
Цвета:
  accent        #0A84FF (iOS blue, светлая) / #64B5FF (тёмная)
  bg light      #F2F2F7 (system grouped)   bg dark   #000000
  surface light #FFFFFF                    surface dark #1C1C1E
  label         #000000 / #FFFFFF;  secondary #8E8E93
  успех #34C759 · предупреждение #FF9F0A · ошибка #FF453A

Радиусы:  карточка 22 · док 32 · чип/кнопка-капсула 999 · поле 14
Тени:     offset (0,10), blur 30, color black 8% (светлая) / black 40% (тёмная)
Стекло:   blur sigma 20; заливка white 78% (light) / #1E1E1E 72% (dark);
          обводка 1.2 px white 60% (light) / white 12% (dark)
Типографика (SF Pro-подобная, letterSpacing отрицательный у заголовков):
  largeTitle 32/700 · title 22/700 · headline 17/600 · body 16/400 ·
  footnote 13/400 · caption 11/500
Отступы экрана: 16 dp (<380) · 20 dp (380–600) · 24 dp (>600)
```

Тактильность: `HapticFeedback.lightImpact()` на переключение вкладок, `selectionClick()` на чипсы, `mediumImpact()` на «в избранное».

## 2. Навигация — плавающий док

`Scaffold(extendBody: true)` + `Stack`: контент на весь экран, док парит поверх.

- Капсула: высота 64, maxWidth 420 (планшет: 480), по центру, отступы left/right 20, bottom = `safeArea.bottom + 6` (если home-indicator есть) иначе 16.
- Пункты: **Главная** (house), **Каталог** (grid), **Избранное** (bookmark), **Другое** (person). Иконка + подпись у активного (анимированное раскрытие, 250 ms easeOutCubic), неактивные — только иконка, grey.
- Активный пункт: капсула-подложка `accent 15%`.
- Референс-реализация дока — `FloatingIosDock` из дизайн-эскиза (см. историю обсуждения), переносится в `core/widgets/glass_dock.dart` с правками: `withOpacity` → `withValues(alpha:)` (новый API Flutter), подписи вкладок синхронизированы с названиями выше.

**Правило скролла:** каждый экран заканчивается нижним padding `safeArea.bottom + 96`, чтобы док не перекрывал последний элемент.

Заголовки экранов — large title, при скролле схлопывается в прозрачный blur-аппбар (`SliverAppBar(pinned: true)` + BackdropFilter).

## 3. Онбординг (первый запуск, 4 шага, пропускаемо)

Полноэкранные шаги с прогресс-точками, large title, крупные тач-цели:
1. **Кампус** — карточки-плитки (Вернадского 78 / Вернадского 86 / Стромынка).
2. **Институт** — список-плитки (ИИТ, ИИИ, ИТХТ, …) + поиск по названию.
3. **Уровень** — сегменты: Бакалавриат / Магистратура / Аспирантура / Не важно.
4. **Интересы** — облако чипсов мультивыбора (IT, Дизайн, Наука, Спорт, Волонтёрство, Стажировки, Кейс-чемпионаты…).

Финал: «Готово» → Главная с уже работающим «Для вас». Всё — в LocalStore, редактируется в «Другое → Мой профиль». Повторно не показывается; кнопка «Пропустить» с первого шага.

## 4. Экран «Главная»

Сверху вниз (CustomScrollView, slivers):
1. **Поиск** — серая капсула (radius 14) с иконкой лупы; фокус раскрывает full-screen search со списком результатов.
2. **Hero-карусель «Приоритетное»** — PageView, высота ~200 dp, крупные карточки с обложкой, градиентом и заголовком; только `is_featured = true`; автопрокрутка 5 с; индикатор-точки.
3. **Чипсы быстрых фильтров** — горизонтальный скролл: Все · Ближайшие · Стажировки · Хакатоны/События · Мой кампус. Активный чип = accent-заливка. Комбинируются с фильтром-листом.
4. **Секция «Для вас»** — заголовок + «настроить» (ведёт в профиль-опрос); горизонтальная лента карточек со скорингом (формула — ARCHITECTURE.md §3). Пуста при непройденном опросе → плейсхолдер «Расскажите о себе».
5. **Секция «Новое»** — вертикальная лента остальных published по `published_at desc`.

Pull-to-refresh (Cupertino-стиль). Realtime: новый published-пост анимированно вставляется в «Новое» (и в hero, если featured).

## 5. Экран «Каталог»

1. Сегмент-контроллер (iOS-style pill): **Вуз** | **Партнёры** — фильтрует `organizations.type`.
2. Кнопка «Фильтры» со счётчиком активных → bottom sheet (Cupertino): тип, формат (онлайн/офлайн/гибрид), кампус, институт, уровень; для «Партнёров» дополнительно — горизонтальный список логотипов компаний (мультивыбор); блок тегов-чипсов; «Показать N результатов» (липкая кнопка с живым счётчиком).
3. Результат — сетка карточек: 1 колонка (<600 dp), 2 колонки grid (≥600 dp, `maxCrossAxisExtent: 380`).
4. Сортировка: сначала «по дате события», переключатель «по популярности» (views).

## 6. Карточка поста (лента)

Горизонтальная, height ~120: обложка 96×96 (radius 16, слева), тип-бейдж (цвет по типу: вакансия — accent, событие — orange, стажировка — green, …), заголовок 2 строки, организатор (логотип 18 + имя, footnote), `event_date`, до 2 тегов-чипсов, кнопка-закладка справа. Tap → детали; long-press → quick actions (в избранное / поделиться ссылкой).

## 7. Экран деталей

- Обложка full-width (parallax при скролле), схлопывающийся назад-кнопка-«стекло».
- Заголовок (title), мета-строки: тип · формат · дата · кампус/институт (если таргетировано).
- Блок организатора: логотип, имя, тип (Отдел вуза / Партнёр).
- Описание — Markdown (`flutter_markdown` или минимальный парсер: bold/списки/ссылки).
- Теги-чипсы (тап = фильтр каталога по тегу).
- Счётчики: 👁 views · 🔖 favorites (анимированный инкремент при тапе закладки).
- **Закреплённая внизу кнопка** «Перейти к регистрации» (accent, capsule, над доком; если `external_link` пуст — блок «Контакты организатора»): открывает системный браузер (`url_launcher`), не WebView.
- Открытие экрана = 1 просмотр (дедупликация через viewed_ids).

## 8. Экран «Избранное»

Вертикальный список тех же карточек; swipe-to-delete (Cupertino); сортировка по дате добавления; пустое состояние — иллюстрация + «Найти интересное в Каталоге». Работает офлайн (локальные id + кэш карточек).

## 9. Экран «Другое»

iOS-списки (grouped inset, ячейки с chevrons):
- **Мой профиль** — повтор опроса (кампус/институт/уровень/интересы), всё редактируемо.
- **Оформление** — тема: системная / светлая / тёмная.
- **О приложении** — версия, лицензия.
- **Карьерный центр РТУ МИРЭА** — контакты, ссылка на сайт.
- **Сбросить локальные данные** (с подтверждением).

## 10. Состояния и крайние случаи

- Нет сети на старте: лента из кэша + тонкий баннер «Офлайн».
- Пустая выдача фильтров: плейсхолдер + кнопка «Сбросить фильтры».
- Загрузка: shimmer-плейсхолдеры карточек (никаких спиннеров в ленте).
- Пост снят с публикации между лентой и деталями: экран «Недоступно» + возврат.
- Длинный текст/заголовки: ellipsize, карточки фиксированной высоты.

## 11. Адаптивность

| Ширина | Ленты | Сетки | Док |
|---|---|---|---|
| < 380 dp | отступы 14, карточки сжаты | 1 колонка | ~92% ширины, подписи активного пункта могут скрываться |
| 380–600 | отступы 20 | 1 колонка, hero выше | капсула maxWidth 420, центр |
| ≥ 600 | отступы 24, контент-колонка ≤ 700 | 2+ колонки | maxWidth 480, центр |

Поворот экрана: только портрет на телефонах, на планшетах — свободный с теми же breakpoint'ами.
