# Карьера РТУ МИРЭА

Мобильное приложение (Flutter, iOS + Android) — агрегатор вакансий, событий и мероприятий вуза и партнёров для студентов, **без регистрации**. Контент создают отделы вуза и компании-партнёры через веб-админку; публикует только главный модератор. Бэкенд — Supabase (Postgres + Auth + RLS + Realtime + Storage).

## Структура репозитория

```
.sdk/                  # Flutter SDK, pub-кэш, инструменты (в .gitignore)
app/                   # Flutter-приложение студента (этапы 2–3)
supabase/migrations/   # SQL: схема, RLS, RPC, seed (этап 1 ✅)
supabase/scripts/      # seed пользователей, smoke-тест прав, загрузка файлов
admin/                 # Vite+TS веб-админка (этап 4)
docs/                  # ТЗ, архитектура, БД, UI, админка, план
.github/workflows/     # релизные сборки Android и iOS
dev.ps1                # сборка и запуск локально: apk, run, connect, test, check
env.ps1                # окружение: все тяжёлые пути внутри проекта, не на C:
```

## Быстрый старт

```powershell
.\dev.ps1            # справка по командам
.\dev.ps1 run        # собрать и запустить на подключённом устройстве
.\dev.ps1 apk        # debug APK
.\dev.ps1 check      # проверка кода
```

Подробности — в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md): BlueStacks, ключи

## Ключевые решения одним абзацем

Flutter вместо KMP (быстрее красивый UI на обе платформы, официальный Supabase SDK). Вся безопасность — в RLS Postgres: аноним физически не может читать неопубликованное и писать статусы (матрица переходов статусов зашита триггером в БД, а не в кнопках админки); счётчики просмотров/избранного — только через `security definer` RPC с колоночными грантами. Персонализация (профиль-опрос, избранное, скоринг «Для вас») — полностью локально на устройстве, без аккаунта. Админка — минимальная SPA на Vite+TS, ровно три флоу для демонстрации: автор → ассистент → главный модератор.
